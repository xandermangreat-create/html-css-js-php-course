# HTML Module

Welcome to the HTML module of the `html-css-js-php-course`!

## Goals
- Learn the basics of HTML (HyperText Markup Language).
- Understand how to structure a webpage.
- Work with forms, tables, and semantic elements.

## Structure
- **Lessons:** Step-by-step guides with examples.
- **Practice Exercises:** Files and tasks to improve your confidence.
- **Project:** Create a basic portfolio website using HTML.

## Lessons
1. Basic HTML structure.
2. Common tags and attributes.
3. HTML forms and inputs.
4. Tables and lists.
5. Semantic HTML.

## How to Use:
1. Go through each lesson in order.
2. Complete the exercises provided in the `exercises/` folder.
3. Build the portfolio project from the `project/` folder.
